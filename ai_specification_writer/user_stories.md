# User Stories

### User Story 1
As a weight-loss seeker, I want to log the foods I eat by searching a food database so that I can track my daily calorie intake.

**Acceptance Criteria**:
- User can search the food database by name and see matching results within 2 seconds.
- User can select a food, set the serving size, and add it to breakfast, lunch, dinner, or snacks.
- Daily calorie total updates immediately after a food is added or removed.

**Priority**: MVP

### User Story 2
As a new user, I want to receive a personalized daily calorie and macronutrient goal so that I know how much to eat to reach my objective.

**Acceptance Criteria**:
- User enters age, sex, height, weight, activity level, and goal (lose, maintain, or gain weight).
- System calculates and displays a daily calorie target and protein, carbs, and fat breakdown.
- User can manually adjust the calculated goals at any time.

**Priority**: MVP

### User Story 3
As a busy professional, I want to scan a product barcode so that I can log packaged foods in seconds.

**Acceptance Criteria**:
- User can open the camera from the food diary and scan a barcode.
- System shows the matching product's nutrition information within 3 seconds.
- If no match is found, user is prompted to search manually or create a new food entry.

**Priority**: High

### User Story 4
As a fitness enthusiast, I want to see my macronutrient breakdown for the day so that I can make sure I hit my protein, carb, and fat targets.

**Acceptance Criteria**:
- Diary shows grams consumed and remaining for protein, carbs, and fat.
- Macros are displayed as a chart showing the percentage of each.
- Values update in real time as foods are logged.

**Priority**: High

### User Story 5
As a fitness enthusiast, I want to log my workouts so that calories burned are added to my daily budget.

**Acceptance Criteria**:
- User can choose an exercise type from a list and enter its duration.
- System estimates calories burned based on exercise type, duration, and user weight.
- Calories burned are added to the remaining daily calorie budget.

**Priority**: High

### User Story 6
As a weight-loss seeker, I want to record my weight over time so that I can see my progress toward my goal.

**Acceptance Criteria**:
- User can enter their weight with a date.
- System displays a line chart of weight history over 1 week, 1 month, 3 months, and 1 year.
- Progress screen shows total weight change and the amount left to reach the goal.

**Priority**: High

### User Story 7
As a health-conscious individual, I want to connect my wearable device so that my steps and activity are imported automatically.

**Acceptance Criteria**:
- User can connect at least Apple Health, Google Fit, Fitbit, or Garmin from settings.
- Activity data syncs automatically at least once every hour.
- Imported activity appears in the exercise log and adjusts the daily calorie budget.

**Priority**: Medium

### User Story 8
As a home cook, I want to import a recipe from a URL or enter its ingredients so that I can log the nutrition of homemade meals.

**Acceptance Criteria**:
- User can paste a recipe URL or enter ingredients manually.
- System calculates total and per-serving nutrition based on the number of servings.
- Recipe is saved and can be added to the diary in future meals.

**Priority**: Medium

### User Story 9
As a health-conscious individual, I want to track my water intake so that I stay properly hydrated.

**Acceptance Criteria**:
- User can log water in cups, milliliters, or ounces with one tap.
- Diary shows water consumed against a daily target.
- User can enable reminders to drink water at set intervals.

**Priority**: Low

### User Story 10
As a dietitian, I want to view my clients' food diaries so that I can give them informed nutrition guidance.

**Acceptance Criteria**:
- Client must grant permission before the dietitian can view their diary.
- Dietitian can see each client's daily calories, macros, and logged meals.
- Client can revoke access at any time from privacy settings.

**Priority**: Low

### User Story 11
As a user looking for motivation, I want to add friends and join challenges so that I stay accountable to my goals.

**Acceptance Criteria**:
- User can search for friends by username or email and send a friend request.
- User can join a challenge and see a leaderboard of participants.
- User controls whether their diary is public, friends-only, or private.

**Priority**: Low
