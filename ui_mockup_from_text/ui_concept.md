# UI Concept - SnapCircle

## Purpose
Help groups collect, share and react to photos from an event in one shared album.

## Users
- Group Owners: create groups and albums, set limits, manage billing
- Members: upload, edit and keep albums in their account
- Guests: join an event by invite link to upload and view
- Admins: oversee the platform and moderate content

## Core Screens
- Home dashboard with groups and recent albums
- Event album feed with reactions and comments
- Upload screen with quick filters
- Invite screen with link and QR code
- Group settings and plan upgrade

## Actions
- Create group and event album
- Invite people by link or QR code
- Upload and filter photos (members and guests)
- React to and comment on photos
- Set group size, album size and photos per person
- Upgrade plan
- Moderate or remove photos
